## 1차 검토

심각도별 결과는 Critical 0건, Major 1건, Minor 4건이다.

| 심각도 | 지적 및 재현 조건 | 기준 | 처리 상태 |
|---|---|---|---|
| Major | 언어 태그가 없는 fenced 코드 블록을 열면 인라인 코드로 렌더링되어 줄바꿈·Copy·가독성이 사라진다. | SPEC 6.2 | 수정 완료. `pre` 구성 요소에서 모든 fenced 코드 블록을 `CodePanel`로 렌더링한다. |
| Minor | `clipboard:write-text` IPC 호출이 거부되면 예외가 처리되지 않아 사용자 피드백이 없다. | SPEC 6.2 | 수정 완료. 예외를 포착해 영어 오류 상태를 표시한다. |
| Minor | 복사 실패 상태가 `role="status"`로 발표된다. | SPEC 6.2 | 수정 완료. 실패 시 `role="alert"`를 사용한다. |
| Minor | `guide.md#section` 또는 query가 있는 상대 Markdown 링크가 main process에서 거부된다. | SPEC 6.4 | 수정 완료. 해시와 query를 제거한 상대 파일 경로만 검증 API에 전달한다. |
| Minor | `file:` 이미지 CSP 및 개발 환경 inline style 허용이 넓다. | SPEC 3.1-3.2 | 보류. 검증된 상대 이미지 결과를 표시하려면 `file:` 이미지 소스가 필요하며, Markdown의 임의 이미지 URL은 구성 요소 대체로 차단된다. 개발 서버의 스타일 삽입에는 `unsafe-inline`이 필요하다. |

## 2차 검토

1차 보완 후 재실행했다. 심각도별 결과는 Critical 0건, Major 4건, Minor 4건이다.

| 심각도 | 지적 및 재현 조건 | 기준 | 처리 상태 |
|---|---|---|---|
| Major | 다른 코드 패널이나 탭으로 이동한 뒤 이전 Copy 상태가 표시될 수 있다. | SPEC 6.2 | 수정 완료. 콘텐츠 또는 언어가 바뀌면 Copy 상태를 초기화한다. |
| Major | 새 Root를 선택한 뒤 이전 Root 탭의 상대 리소스가 새 Root 경계 밖으로 판정된다. | SPEC 3.1-3.2 | 보류. 기존 탭의 원문은 유지하지만 상대 리소스와 링크는 현재 창의 선택 Root에서 다시 검증해 차단한다. 경계를 완화하지 않는 보안 우선 동작이다. |
| Major | HTTP/HTTPS 외부 링크 열기에 실패해도 오류가 보이지 않는다. | SPEC 6.1 | 수정 완료. preload 결과 실패를 파일 오류 상태로 표시한다. |
| Major | Renderer의 `.md` 확장자 판단과 main process 분류가 달라 링크가 실패할 수 있다. | SPEC 6.4 | 수정 완료. 모든 상대 링크를 main process의 `markdown` 검증 API에 위임한다. |
| Minor | JSON 속성 키 하이라이트가 적용되지 않는다. | PRD FR-19 | 수정 완료. 속성 키와 콜론을 하나의 토큰으로 처리한다. |
| Minor | 대형 코드 파일에서 토큰별 span 생성이 UI 정지를 유발할 수 있다. | PRD FR-22 | 수정 완료. 512 KiB 초과 코드에는 토큰화 없이 읽기 전용 원문을 표시한다. |
| Minor | `#`, `?`를 포함한 실제 파일 경로가 `file:` URL에서 절단될 수 있다. | SPEC 6.3 | 수정 완료. 파일 경로 세그먼트를 URL 인코딩한다. |
| Minor | raw href 처리 의존성이 남아 있다. | SPEC 3.1-3.2 | 처리 완료. 상대 경로는 제한된 main-process 검증 API에만 전달하고, 외부 경로는 HTTP/HTTPS allowlist IPC 결과를 확인한다. |

두 차례 검토 모두 Root 경계 우회, raw HTML 실행, Renderer Node.js 권한 상승, sandbox/contextIsolation/webSecurity 우회 재현에는 실패했다. 유효 Critical은 없다.
